# AWS Secure Cloud Infrastructure

## About the Project

This project involved designing and building a secure and scalable cloud infrastructure using Amazon Web Services (AWS). The main goal was to understand how cloud resources can be configured to support secure access, network isolation and reliable application hosting.

## AWS Services Used

- Amazon VPC: Created a virtual network to organise cloud resources.
- Private Subnets: Isolated resources from direct public access.
- Amazon EC2: Used virtual servers to host applications.
- Bastion Host: Provided controlled access to instances in private subnets.
- Load Balancer: Distributed incoming traffic.
- Auto Scaling: Supported application availability by adjusting computing capacity.
- Amazon RDS (MySQL): Used for database hosting.
- Amazon S3: Used for cloud storage.
- IAM: Managed user permissions and access.
- AWS WAF: Helped protect web applications.
- AWS CloudTrail: Supported activity logging and monitoring.

## Security Focus

The project focused on network isolation, access control, infrastructure protection and monitoring of AWS activity.
